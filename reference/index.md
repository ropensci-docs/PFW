# Package index

## Downloading and Importing

- [`pfw_download()`](https://docs.ropensci.org/PFW/reference/pfw_download.md)
  : Download Raw Project FeederWatch Data by Year
- [`pfw_import()`](https://docs.ropensci.org/PFW/reference/pfw_import.md)
  : Import Project FeederWatch Data
- [`pfw_example`](https://docs.ropensci.org/PFW/reference/pfw_example.md)
  : Example Project FeederWatch Dataset
- [`update_taxonomy()`](https://docs.ropensci.org/PFW/reference/update_taxonomy.md)
  : Update the Project FeederWatch Species Translation Table
- [`pfw_sitedata()`](https://docs.ropensci.org/PFW/reference/pfw_sitedata.md)
  : Merge Site Metadata into Project FeederWatch Data

## Filtering and Zerofilling

- [`pfw_filter()`](https://docs.ropensci.org/PFW/reference/pfw_filter.md)
  : Apply Multiple Filters to Project FeederWatch Data
- [`pfw_region()`](https://docs.ropensci.org/PFW/reference/pfw_region.md)
  : Filter Project FeederWatch Data by Region
- [`pfw_species()`](https://docs.ropensci.org/PFW/reference/pfw_species.md)
  : Filter Project FeederWatch Data by Species
- [`pfw_date()`](https://docs.ropensci.org/PFW/reference/pfw_date.md) :
  Filter Project FeederWatch Data by Month and/or Year
- [`pfw_rollup()`](https://docs.ropensci.org/PFW/reference/pfw_rollup.md)
  : Do Taxonomic Rollup on Project FeederWatch Data
- [`pfw_truncate()`](https://docs.ropensci.org/PFW/reference/pfw_truncate.md)
  : Filter Project FeederWatch Data to "Standard" Seasonal Window
- [`pfw_zerofill()`](https://docs.ropensci.org/PFW/reference/pfw_zerofill.md)
  : Zerofill Species not Detected in each Survey Instance for Analysis

## Helper Functions

- [`pfw_attr()`](https://docs.ropensci.org/PFW/reference/pfw_attr.md) :
  View Filter Attributes on Manipulated Project FeederWatch Data
- [`pfw_dictionary()`](https://docs.ropensci.org/PFW/reference/pfw_dictionary.md)
  : Look Up Definitions from the Project FeederWatch Data Dictionary
